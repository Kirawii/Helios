# Helios

本地运行的论文阅读助手。参考 Moonlight 公开页面和用户提供的阅读器布局，独立实现，不是原站源码。

## 启动

主应用保留原来的阅读与覆盖式翻译界面。**PDF 识别与重排阅读**在独立调试页 `http://localhost:3210/ocr-debug/` 中进行，使用 PaddleOCR PP-StructureV3，提供内容类型、阅读顺序编号、原文对照和文本校对。安装、资源限制和验证边界见 [识别与排版说明](RECOGNITION.md)。

需要 Node.js 20 或更高版本。

```powershell
npm install
npm start
```

打开 http://localhost:3210 。上传 PDF 后进入阅读器。在设置中配置模型：

OCR 调试支持两种方式：本地部署需另行运行 `npm run setup:ocr`（Python 3.12），无需 API Key；硅基流动 API 方式填写 Key 和 OCR 模型，无需安装本地 OCR。访问 `/ocr-debug/`，选择识别方式和 PDF 后点击“开始全文识别”。主应用的模型设置用于问答和原有翻译。

API 默认使用混合解析：保留 PDF 文字层与行坐标，仅将图像和疑似公式区域送给 `PaddlePaddle/PaddleOCR-VL-1.5`，扫描页回退整页 OCR。区域跨页流水线并发，默认 8 路，可调 1–32；缓存成功区域，失败后只补缺失部分。调试页分别显示文字页数、区域完成数、失败数和实际耗时，未完成区域不会记为全文完成。此优化暂用于 API 方式，本地完整 PaddleOCR 流程保留。不能保证公共云 API 的全文 2 秒延迟。

启动时预热 PDF.js 和常驻本地线程池，默认最多 4 个线程；`HELIOS_PDF_WORKERS=1–8` 可调整，独立于 API 并发。布局与裁剪 PNG 保存在 `.cache/pdf-preparation/`，OCR 结果缓存会在渲染前查询，重试可跳过本地计算；修改文档内容或准备实现会使对应准备缓存失效。公式候选、提示词和公式 PNG 输入保持不变。对照基准：`node scripts/benchmark-ocr-preparation.cjs paper.pdf report.json`，只测本地准备，不调用云服务。

本地准备和 API 请求使用独立队列：同页最多 16 个区域一次裁剪传输，按页打包保存 PNG 与校验和，已知布局中绘图指令较多的页优先准备。等待云端响应时本地仍可推进，结果缓冲上限为 128 个区域、32 MiB；单个超大图片可独占缓冲，保持原图分辨率。调试页分别显示本地准备完成时间和 API 处理中数量。

- Ollama：地址 `http://localhost:11434/api`，填写已安装的模型名，如 `qwen3:8b`。
- LM Studio：地址 `http://localhost:1234/v1`，填写加载的模型名。
- 其他 OpenAI 兼容接口：填写包含 `/v1` 的基地址。

PDF、聊天、笔记、译文保存在 `data/`。模型配置保存在浏览器 localStorage，API 密钥只保存在当前网页会话内存中。服务仅监听本机回环地址。

## 当前范围与限制

支持 PDF 上传与文本选择、分页缩放、目录书签、文本查找、本地论文库与真实首页缩略图、收藏、持久化空文件夹、时间排序、选区解释、流式问答与停止生成、关键词、摘要、测验、逐页并排翻译、手动高亮、笔记、Markdown 导出、主题与侧栏布局。可选择最多 4 篇参考论文参与问答。自动高亮会把模型返回的原文句子与已渲染 PDF 文本层精确匹配，匹配成功后保存标注。

尚未做到原站全部功能或像素与动画完全一致。首页基于已观察画面用本地 CSS 重建，使用本地阅读器截图，没有下载原站静态素材。加入了滚动入场、功能切换、FAQ 展开、弹窗及侧栏过渡，并遵循减少动态效果设置。原站动画时长尚未逐项测量。

主应用使用按 PDF 坐标覆盖译文的实现与原有缓存；PaddleOCR 识别结果的自然重排仅在独立 OCR 调试页展示。内部引用使用 PDF 原有链接注释，可悬浮预览目标区域并跳转至目标页。详细观察与实现边界见 [IMPLEMENTATION-NOTES.md](IMPLEMENTATION-NOTES.md)。

没有原站账号、支付、团队、分享、Scholar Deep Search、视觉图表分析。识别版面由 PaddleOCR 提供；复杂公式、表格、旋转文字与多栏仍可能识别不准确，需要对照校对。新的识别视图启用完整 PP-StructureV3，公式转为 LaTeX、表格还原 HTML、图表解析数据，并保留校正页面与原图供核对；旧覆盖式译文数据继续保留。无链接注释的纯文字引用暂不自动识别。旧问答接口最长输入截取论文前 100000 字符；添加参考论文时当前论文最多 65000 字符，每篇参考最多 8000 字符。原文高亮匹配依赖模型按指定 JSON 格式返回且保留原句。

API 未配置或模型服务不可用时明确报错，不生成模拟 AI 回答。请按模型能力与隐私需求选择地址；论文内容会发送到你配置的服务。

## 验证

```powershell
npm test
```

验证 PDF 导入、文本提取、文件下载、笔记保存、错误文件处理，以及 Ollama/OpenAI 的普通与流式协议、中文传输、参考论文上下文、上游错误和地址标准化。另验证段落连续性、双栏分离、数值保留、几何坐标和翻译 JSON 完整性。自动测试使用独立临时目录，不改动文献库。浏览器联调用的合成文档明确标注为“功能验证样本”，译文来自独立测试服务；没有使用真实模型验证翻译或回答质量。
