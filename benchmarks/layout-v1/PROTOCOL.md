# Helios layout mini benchmark v1

冻结日期：2026-11-02。6 篇论文，每篇固定 2 个物理 PDF 页，共 12 页。页码与版本在 `manifest.json` 冻结，下载后使用 SHA-256 锁定文件。不将重复文档、合成 PDF 或同一论文的不同版本计为独立论文。PDF 保存在本地缓存或原文献库，不随评测代码分发。

## 比较与边界

- Baseline：线上相同模型、800×800 输入和后处理，所有类别阈值 0.5。
- Candidate：同一份推理输出，仅行内公式类别 15 的阈值改为 0.45；其他类别保持 0.5。不增加局部复检，不改变 OCR 请求。
- 2 篇已用于开发的论文只报告 development 结果；4 篇新加入论文作为冻结 holdout 单独报告。Holdout 指本项目调试过程未使用，不能证明未进入布局模型的训练集。
- 评测输出与服务状态分离，不覆盖 `data/`，不修改生产阈值，不调用云端 OCR/翻译。
- 本轮首先衡量公式定位。不会把公式指标称为所有 25 类的布局 mAP，也不评价 LaTeX 转写或译文准确率。

## 人工参考标注

先看未叠加模型预测的原页，再冻结完整页标注，最后运行配置对比。标注记录来源、审阅状态和页图尺寸。单人视觉标注作为 v1 silver reference，不能称为多人审定 gold；后续允许独立复核，但修改须升级标注版本并重跑两组。

坐标为原页归一化 `[x0,y0,x1,y1]`。公式对象：

- `inline_formula`：正文、图注或脚注中的独立数学符号/表达式，包括有数学意义的单变量；整条连续表达式只标一个框。
- `display_formula`：独立展示的一组公式；相连多行公式作为一组。公式编号另标元数据，不并入公式框。
- 排除章节/页码/引用编号、普通数值叙述、普通英文缩写和模型名字。架构图、图表、表格内部数学标签不在本轮正文公式范围；须独立画 ignore 区并注明原因。
- 框紧贴可见数学内容，含上下标，不含句末标点。所有 eligible 公式应完整标出；不能只标已知漏检点，也不能从模型框直接生成参考答案。
- 没有公式的页必须显式标记 complete，预测公式计为误检。未完成标注的页不参与质量汇总，报告标注覆盖率，不能当作负例。

另外手工指定少量正文/标题/图注的阅读先后锚点。忽略页眉、页脚、图内文字。原始模型顺序与应用层排序分别评价；锚点未定位、被合并成同一块均计入 strict 分母并明确报告。

## 指标

- 公式定位：按类别、IoU≥0.5 一对一最大匹配的 TP/FP/FN、Precision/Recall/F1；另报告 0.3/0.75 敏感性。重复框只允许一次匹配，多余框计 FP。先匹配正例，再忽略主要落于 ignore 区的未匹配预测。
- 按论文汇总后分别报告 development/holdout 的 micro 及 macro；未定义的 P/R 为 null，不伪装成满分。额外展示无公式页 FP 数。
- 公式对齐：已检测真实公式中，可映射原文连续范围的数量与比例；单独报告实际候选任务总数、unresolved 数，不将其当作召回率。
- 原生文字：每个 Run 恰好保留一次，记录未匹配字符比例。文字保留率不代表布局类别或阅读顺序正确。
- 阅读顺序：人工锚点的先后关系正确率、锚点覆盖率与 strict 正确率；区分 raw/model 与 application/fallback。
- 速度：模型校验/创建、预热、单页原图渲染及输入准备、热推理 p50/p95，注明设备与重复次数。模型热推理在同一输入重复三次，绝不将它称作 OCR 端到端延迟。共享同一次推理输出的阈值对照不宣称推理加速。

## 使用结果的条件

先看 holdout 的新增 TP 与 FP，再判断是否接受降低阈值；开发集的漏检恢复只是回归证据。样本只有 6 篇，结果用于工程决策，不作总体准确率或统计显著性结论。不根据 holdout 结果继续调阈值后仍称其为未见测试集；后续调参需新版本或新 holdout。
